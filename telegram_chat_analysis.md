# Анализ чек-листов менеджеров из Telegram

## Задача
Проанализировать планы менеджеров за последние 2 месяца и найти все невыполненные задачи.

## Источник данных
- Чат в Telegram: "Vera & Антон & Elena & Nastya & German"
- Менеджеры пишут планы через встроенные чек-листы Telegram
- Закреплённые сообщения содержат списки задач

## Что нужно сделать

### 1. Получить API-ключи Telegram
- Зайти на https://my.telegram.org
- Войти по номеру телефона
- Перейти в "API development tools"
- Создать приложение:
  - **App title:** `Plans Analyzer`
  - **Short name:** `plans_analyzer`
  - **URL:** `https://localhost` (или оставить пустым)
  - **Platform:** `Desktop`
  - **Description:** `Скрипт для выгрузки и анализа чатов`
- Скопировать `api_id` и `api_hash`

### 2. Установить зависимости
```bash
pip3 install telethon
```

### 3. Скрипт выгрузки и анализа
Скрипт должен:
1. Подключиться к чату через Telethon
2. Выгрузить все сообщения за последние 2 месяца
3. Найти закреплённые сообщения с чек-листами
4. Распознать структуру: план задач vs выполненные (отмеченные)
5. Сохранить результат в таблицу (CSV/Excel) с колонками:
   - Дата
   - Менеджер
   - Задача
   - Статус (выполнено/не выполнено)

### 4. Ключевые файлы проекта
- Скрипт выгрузки: `export_chat.py`
- Скрипт анализа: `analyze_plans.py`
- Результат: `plans_report_YYYY-MM-DD.csv`

## Примечания
- Python 3.9.6 установлен: `/usr/bin/python3`
- Чат создан пользователем, есть полный доступ
- Менеджеры: Антон, Elena, Nastya, German
