# Team Analyst Bot 🕵️‍♀️📈

Бот для автоматического анализа продуктивности команды в Telegram. Он отслеживает нативные списки задач (Checklists), фиксирует их выполнение и формирует отчеты по запросу администратора.

## 🚀 Основные функции
- **Тихий мониторинг**: Бот находится в группе с командой, фиксирует создание и редактирование списков задач, но ничего не пишет в общий чат.
- **Приватные отчеты**: Бот общается **только с Верой**. На любые запросы от других пользователей он отвечает: *"ты не Вера, я тебе не помогу)"*.
- **Аналитика по запросу**: По команде `/report` в личных сообщениях бот выдает срез:
  - Кто из менеджеров поставил задачи.
  - Процент выполнения по каждому сотруднику.
  - Список конкретных задач, которые «тянут» (не выполнены).

## 🛠 Технологии
- **Python 3.11** + **aiogram 3** (движок бота)
- **SQLAlchemy** + **aiosqlite** (асинхронная работа с БД SQLite)
- **Docker** + **Docker Compose** (изолированное окружение и легкий деплой)
- **GitHub Actions** (автоматический деплой на VPS при каждом пуше)

## 📦 Структура проекта
- `bot.py` — основная логика и парсинг сообщений.
- `models.py` — описание таблиц базы данных.
- `database.py` — инициализация и подключение к БД.
- `data/` — папка с файлом базы данных `analytics.db` (игнорируется гитом).
- `.env` — файл с токенами и ID (игнорируется гитом).

## 🚢 Деплой на сервер
Проект настроен для работы на VPS в Docker-контейнере.
1. На сервере используется `docker-compose.yml`.
2. БД хранится в volume `./data`, что гарантирует сохранность данных при перезапуске контейнера.
3. Обновление происходит автоматически через GitHub Actions.
