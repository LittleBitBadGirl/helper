# Team Analyst Bot (@helper_vera_bot)

Аналитика нативных чек-листов Telegram для мониторинга выполнения планов.

## Основные возможности
- **Сбор данных**: Бот автоматически парсит сообщения с чек-листами в группах.
- **Приватные отчеты**: Бот общается **только с Верой** (ID: 163394712).
- **Команды**:
    - `/start` — приветствие и проверка прав доступа.
    - `/report` — генерация сводного отчета по всем пользователям и их прогрессу.

## Технический стек
- **Язык**: Python (aiogram 3)
- **БД**: SQLAlchemy (SQLite + aiosqlite)
- **Инфраструктура**: Docker Compose, GitHub Actions (автодеплой)

## Как смотреть логи
Для просмотра логов в реальном времени зайдите на VPS и выполните команду:
```bash
cd /root/projects/analitics_manager
docker compose logs -f bot
```

## Деплой и конфигурация
- **Автодеплой**: Настроен через GitHub Actions. При пуше в `main` бот автоматически пересобирается на сервере.
- **Переменные окружения** (.env):
    - `BOT_TOKEN`: Токен от BotFather.
    - `ADMIN_ID`: Ваш Telegram ID (163394712).
    - `DB_URL`: Путь к БД (используйте `sqlite+aiosqlite:////app/data/analytics.db` для Docker).
- **Логирование**: Включен флаг `PYTHONUNBUFFERED=1` в `docker-compose.yml` для мгновенного отображения логов.

## Разработка
При внесении изменений в схему БД (модели), функция `init_db()` автоматически обновит таблицы при старте контейнера.
